# 決定事項と未決事項

更新日：2026-11-18

## 記録の基準

ユーザーの指定を確定事項とする。相談中の提案、画面ラフ上の表示、過去のAI案は、承認された仕様と区別する。詳細な現行仕様は[GAME_DESIGN.md](GAME_DESIGN.md)を参照。

## 2026-11-18 決定・変更履歴

ROADMAPの「試作の中で決める事項」3点を決め、Godotプロジェクトを作成した。

| 項目 | 決定・変更 | 理由・背景 |
| --- | --- | --- |
| サキュバスの幻惑魔法 | 範囲内の敵1体を数秒間同士討ちさせる（最も近い敵を攻撃する） | ユーザーが実装構成案の提案を採用 |
| 全体攻撃力アップの対象範囲 | 施設と配下の両方に効かせる | ユーザーが実装構成案の提案を採用 |
| 採掘先の指定方法 | 準備中に周辺の岩盤セルをタップして指定する。複数指定はタップ順のキューとし、wave 終了時に盤面の拡張と資材の獲得を反映する | ユーザーが実装構成案の提案を採用 |
| Godotプロジェクト | `game/` に新規作成した。構成は Main／Board／Pathfinding／WaveManager／ManaSystem／GlobalMagic／Minion／Enemy／Economy／KoboldMine。数値は `game/scripts/balance.gd` に試作仮値として集約した | ユーザーが実装構成案を承認 |

## 2026-11-17 決定・変更履歴

ゲーム全体の骨格を決めた。内容は[OVERALL_DESIGN.md](OVERALL_DESIGN.md)にまとめている。

| 項目 | 決定・変更 | 理由・背景 |
| --- | --- | --- |
| ゲームの形 | 一人で遊ぶ。wave をクリアすると次の wave を解禁する | ユーザーが進行の単位を指定 |
| 襲撃の起こり方 | プレイヤーが自分で開始し、見ながら指揮する | 指揮と全体魔法が意味を持つ形を選択。実時間で来襲する案は不採用 |
| 魔力 | 実時間蓄積（毎時6・上限70）を廃止。戦闘中に地下から湧き、タンクの上限まで貯まる。残量は持ち越す | 一人用で wave を解禁していくゲームに、待ち時間は合わないとユーザーが判断 |
| 資材 | wave の間に採掘し、wave 終了時に獲得する。失敗した wave でも掘った分は入る | 準備中の待ち時間をなくすため |
| 資金 | wave クリアの報酬。再挑戦は可能で、2回目以降は減額する | 資金の入手元が未決だった点を解消。詰まったときの手段を残す |
| 撤去 | 設置した施設の撤去は全額返還 | 稼ぐ前に配置を組み直せるようにする |
| 資源の使い道 | 設備の設置は資材と資金、配下の雇用は資金、魔法研究は魔力と資金、武器研究は資金と資材 | ユーザー指定 |
| 守る対象と勝敗 | ダンジョンコア（魔力タンク）が破壊されなければ勝利。破壊されれば失敗で再挑戦 | ユーザー指定。成績評価の案は不採用 |
| 損失 | 壊れた施設は戦闘後に自動で復旧。倒された配下も wave 終了後に復帰 | 再挑戦を軽くし、方向不明の侵入による不運を許容する |
| 防衛の役割分担 | 施設は準備中の読み、配下は戦闘中の移動による対応、全体魔法は即時の補完 | 侵入方向が事前に分からないことを判断の材料にする |
| 配下への指示 | 戦闘中に配下をタップし、行き先をタップして移動させる | 方向不明への対応を配下に持たせる |
| 戦闘中の建設 | 行わない | 施設と配下・魔法の役割を分ける |
| 人物の扱い | コボルド（採掘所）、ドワーフ（工房）、エルフ射手（弓塔）、魔術師（魔法塔）は施設の一部。個別に扱うのは配下と魔王 | ユーザー指定。塔への配属方法が未決だった点を解消 |
| 配下の加入 | 資金で雇用する | ユーザー指定 |
| ダンジョンLv | そのLvの最後の wave をクリアすると上がる。施設・研究・装備・資源は持ち越す。施設レベルの上限はLvで決まる | Lvを章として扱う。資源を払って上げる案は不採用 |
| 侵入ルール | 外周全体から出現。事前に見せるのは編成と方向の数。出現位置は wave 開始時に抽選。現れた瞬間に見える | 準備の手がかりを残しつつ、位置は不明に保つ |
| 完全封鎖 | 禁止しない。防壁は高い代償で通れるマスとし、敵は迂回と破壊の安い方を選ぶ | 模擬襲撃の実装と同じ考え方。特別なルールを設けない |
| 盤面 | 初期は7×7程度。周辺の岩盤を採掘すると広がる | ユーザー指定 |
| 数値 | 試作で遊びながら決める | ユーザー指定 |
| wave の終了 | 敵が全滅したら終わる | ユーザー指定。制限時間は設けない |
| 採掘所 | 当面、拡張担当のコボルドが出入りする動きを見せるためだけの設備とする | ユーザー指定。簡易化のため、ゲーム上の機能を持たせない |
| 最初の全体魔法 | 数秒間の全体攻撃力アップ | ユーザー指定 |
| 最初の配下 | デーモン（純粋に戦闘力が高い。4本腕、バフォメットを思わせる姿）とサキュバス（幻惑魔法を使う。女性のキャラクター） | ユーザー指定 |
| 開発エンジン | Godot 4.7系で確定。次の試作から直接Godotで作り、HTML試作は組み替えない | KayKitのglTF素材をそのまま読める、3Dのまま2.5D表示にできる、テキスト中心でAIとの共同作業に向く、無料。HTMLで組み替えてから移すと二度手間になる |
| 対象端末 | Android | ユーザー指定。Macがないため iPhone向けは対象にしない |

この決定により、2026-11-16の履歴のうち「魔力供給」「研究の試作値」「Lv1試作の表示・時間」「保存と精算」は廃止、「資源の試作案」「Lv1試作の範囲」「掘削と経路」は内容を変更した。「掘削と経路」は、採掘が戦闘中の経路に影響しない点を維持し、wave 終了時に盤面が広がることを認める形に改めた。

## 2026-11-16 決定・変更履歴

| 項目 | 決定・変更 | 理由・背景 |
| --- | --- | --- |
| 主人公 | 人間の魔術師が魔王を名乗り、琥珀色の魔力を使う | ユーザーが今回の企画の軸として提示 |
| プレイヤーの立場 | 指揮官寄り | 魔王は研究と全体魔法、配下は迎撃・戦闘を担当 |
| 作業分担 | コボルドが採掘、ドワーフが武器防具の製作・改良 | ユーザーが四役を明示 |
| 盤面 | ヘックス案を正方グリッドの斜め描写へ変更 | 制作しやすさを踏まえた方針変更 |
| 画面 | スマホ横画面、2.5D斜め見下ろし | Clash of Clansを画面の参考にする指定 |
| 掘削と経路 | 掘削は資源獲得、防衛経路は防壁配置として分離 | 掘削が敵の進路を作る旧案を撤回 |
| 侵入地点・方向 | 事前には分からない。固定の侵入口と侵入地点の予告マーカーを置かない | 固定入口だけに備える前提から、複数方向への備えを考える設計へ変更。敵出現・戦闘はラフに未実装 |
| 設置 | 防衛施設・兵器・罠・防壁を自由配置 | プレイヤーが防衛構成を作る指定 |
| 画面構成 | メインで掘削・配置、研究／武器防具画面へ遷移 | ユーザーが画面ごとの操作を指定 |
| 画面領域 | 上下の帯で盤面を狭めず、下部の横幅いっぱいの帯は設けない。状況表示を置く場合は上側のみ | ユーザーが盤面の表示領域を優先すると指定 |
| 表示の削除 | 「地下拠点」「配置を確認」「第1層／第一層」の常時ラベルと、＋／−のズームボタンを廃止 | ユーザーが不要な表示・操作部品を明示 |
| 施設・守備隊の名称 | 通常は非表示。PCのマウスオーバー、スマホのタップ時に対象の名称だけを表示 | 研究室・魔力核・工房・守備隊などの文字を必要なときだけ確認する指定 |
| 初期登録 | 仕様と既存画面ラフをリポジトリで管理 | 今回は企画の共有が範囲。Godot本実装は含めない |
| ダンジョンの成長 | Lv1から始めてレベルアップする | ユーザーが成長の単位を指定。施設のレベルとは区別する |
| 魔力供給 | 地下から自動的に汲み上げる。未研究のLv1は毎時6・上限70 | ユーザー指定。空から約12時間で満杯にする意図で、正確には11時間40分 |
| 施設強化 | 1〜2種類の資源を消費してレベルアップする | ユーザー指定。具体的な費用は試作値として扱う |
| 資源の試作案 | 魔力・資材・資金の3種類をLv1試作で扱う | ユーザー案を試す段階。資金の入手元は未決 |
| 塔の表現 | 弓塔にはエルフ射手、魔法塔には魔術師を置く方針 | アセットを探す際の方向性。配属方法や駐留者の管理は未決 |
| Lv1試作の範囲 | 外観・準備・経済、魔力の2研究、井戸以外の施設Lv1→2を扱う | 実アセットを使った最小構成の確認へ拡張。戦闘、資金収入、ダンジョンLv2進行は含めない。指定値と仮値は[LEVEL_ONE.md](LEVEL_ONE.md)で区別 |
| 魔力改善の担当 | 汲み上げ量と蓄積上限を研究で改善。井戸の施設強化を廃止し、選択時は研究へ案内 | ユーザーの研究方針を反映 |
| 研究の試作値 | 各0→1、即時完了、＋20％を仮採用 | 上昇率・費用・即時完了は試作上の選択。時間と後続レベルは未決 |
| Lv1試作の表示・時間 | 研究・工房は別画面。魔力は非表示・オフラインでも実時間で蓄積、採掘は表示中だけ | 旧版の「非表示中は全停止」から変更。資金収入は追加しない |
| Lv1のアセット外観 | 実際のKayKitモデルと専用モデルを描画し、暗い洞窟・琥珀色の魔力の2.5D画面へ組み込む | ユーザーがアセット組込み後の見た目を最小構成で確認すると指定。初期施設は増やさず、元データと再生成処理を保存 |
| 保存と精算 | 状態と時刻をlocalStorageへまとめて保存。研究変更前に旧速度・旧上限で精算 | 非対応環境ではセッション内動作。魔力・研究・保存処理はロジック確認済み、実機確認は未実施 |

## 未決事項と理由

| 未決事項 | 現在ある案・決める理由 |
| --- | --- |
| 採掘 | 採掘量を伸ばす手段。採掘先の指定方法は2026-11-18に決定。採掘所は当面機能を持たない |
| 工房の置き場所 | 盤面に置くか |
| 盤面の拡張 | wave 終了時に反映する案、拡張後の外周から敵が出現する案、ダンジョンLvで拡張の上限を決める案。いずれも提案 |
| 盤面を広げ切った後の資材 | 掘る岩盤がなくなった後の入手方法が必要 |
| 配下 | 枠の数、能力値、装備の割り当て方法。3種目以降の種族（幻惑魔法の具体的な効果は2026-11-18に決定） |
| 魔王と全体魔法 | 2種目以降の魔法。魔王本人を盤面に出すか（全体攻撃力アップの対象範囲は2026-11-18に決定） |
| 研究 | 魔力以外の対象、段階数 |
| 施設強化の費用 | 1〜2種類の資源という範囲は確定。内訳は未決 |
| ダンジョンLv | Lvごとの wave 数、最大Lv |
| 戦闘操作 | 一時停止や速度変更の有無。掘削・配置ボタンの位置、拡大縮小の操作方式 |
| 開発方式 | 3Dモデルを正投影で映す描画方式は第一候補 |
| 販売形態 | 同人ソフトとして買い切りにする可能性がある |
| 名称 | 作品名 |

数値は試作で遊びながら決める。研究名や費用などの仮設定を確定値として扱わない。原作の追加設定を推測で埋めない。
