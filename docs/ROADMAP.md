# 開発の進め方

更新日：2026-11-18。以下の実装順は提案であり、工数やリリース日を確定するものではない。

## 現在：全体設計が決まった段階

2026-11-17に、ゲーム全体の骨格を[全体設計](OVERALL_DESIGN.md)として決めた。進行は wave 単位、襲撃はプレイヤーが開始、魔力は戦闘中に湧く資源、という構造である。

既存のHTML試作は、その前日までの旧仕様（魔力の実時間蓄積）で作ったものである。実アセットによる外観、配置操作、画面遷移、模擬襲撃の経路探索は確認できるが、現行仕様の進行と経済は実装していない。旧試作の内容は[LEVEL_ONE.md](LEVEL_ONE.md)と[COMBAT.md](COMBAT.md)に記録がある。

## 次の試作：Godotで wave 構造を作る

Godot 4.7系で wave 構造の最小の試作を作り、骨格が面白いかを確かめる。既存のHTML試作は組み替えず、外観と操作の参考として残す。Godotのプロジェクトは2026-11-18に `game/` へ作成した。

**検証する問い：** 方向の分からない侵入に対して、施設で薄く備え、配下と全体魔法で厚くする判断が面白いか。

1. 7×7の盤面で、ダンジョンLv1の wave を3つ用意し、クリアで次を解禁する。
2. 魔力を戦闘中に湧く資源へ変更し、全体魔法（数秒間の全体攻撃力アップ）を入れる。残量は次へ持ち越す。
3. 配下としてデーモンとサキュバスを置き、タップで移動を指示できるようにする。
4. wave クリアで資金、wave 終了で資材を獲得し、採掘した周辺の岩盤の分だけ盤面を広げる。
5. 再挑戦の報酬は減額、施設の撤去は全額返還とする。
6. wave 開始前に、敵の編成と方向の数を表示する。
7. 実時間の蓄積、オフライン精算、準備中の採掘待ちは作らない。

**完了条件：** 3つの wave を通して遊べる。配置を変えると結果が変わる。同じ wave の再挑戦で侵入方向が変わり、展開が変わる。準備中に待ち時間が発生しない。

数値はこの試作で遊びながら決める。

wave は敵の全滅で終わる。採掘所は、コボルドが出入りする動きを見せるだけの設備として置く。

**試作の中で決める事項**（2026-11-18にすべて決定。詳細は[DECISIONS.md](DECISIONS.md)）

- サキュバスの幻惑魔法：範囲内の敵1体を数秒間同士討ちさせる。
- 全体攻撃力アップの対象範囲：施設と配下の両方に効かせる。
- 採掘先の指定方法：準備中に周辺の岩盤をタップして指定する（複数指定はタップ順、反映は wave 終了時）。

## 本体の実装

wave 構造の試作の結果を見て、本体の実装範囲を決める。対象端末は Android とする。エンジンは Godot 4.7系、言語は GDScript とする。3Dモデルを固定方向の正投影カメラで映す描画方式が第一候補である。

**完了条件：** 試作で確かめた1サイクル（準備、戦闘、結果）が本体で動く。

## 研究・武器・配下の拡充

魔法研究（魔力の供給量と上限、全体魔法）、武器研究（配下の装備）、配下の雇用を具体化する。研究の段階数、装備の割り当て方法、配下の種族と枠を決める。

**完了条件：** 研究、資源消費、雇用、装備、防衛での効果が一続きで確認できる。

## ダンジョンのレベルアップ

Lv1の wave を通して遊べるようになった後、Lv2で増える要素を決める。採掘で広げられる範囲、施設の種類と上限、配下の枠、敵の種類が対象になる。Lvごとの wave 数と最大Lvは未決。施設レベルの強化とは別の進行として設計する。

## スマートフォンでの調整

Android の対象機種と画面寸法を選んで、指による選択、遮蔽、画面端の余白、文字の読みやすさを確認する。戦闘中に配下をタップして移動させる操作が、誤操作なく行えるかを重点的に見る。上側の状況表示と浮動ボタンで必要な情報・操作を保ち、固定の下部帯は作らない。
