# 防衛ゲーム 全体仕様

更新日：2026-11-17  
状態：世界観、役割、画面の仕様。進行、勝敗、資源、防衛手段、盤面、侵入の骨格は[全体設計](OVERALL_DESIGN.md)にまとめ、この資料では要点だけを示す。確定、提案、未決を分けて記録する。

## 企画の中心

『魔王の始め方』に着想を得た、地下拠点を築いて侵入者を迎撃する防衛ゲーム。主人公は魔王を名乗る人間の魔術師で、琥珀色の魔力を特徴とする。プレイヤーは指揮官寄りの立場で、採掘、研究、装備、防衛を組み合わせる。原作について未確認の設定は追加せず、ゲーム独自の案を原作設定として扱わない。

一人で遊ぶゲームであり、wave を順にクリアして進める。Clash of Clansは画面の見た目と操作感の参考である。対人戦、オンライン運営、実時間の建設待ちは採用しない。

## 確定している仕様

| 項目 | 確定事項 |
| --- | --- |
| 利用画面 | スマートフォンの横画面で遊びやすくする |
| 視点・盤面 | 2.5Dの斜め見下ろし。正方グリッドを斜めに描写する |
| 盤面の広さ | 初期は7×7程度。周辺の岩盤を採掘すると広がる |
| 進行 | wave をクリアすると次の wave を解禁する。襲撃はプレイヤーが開始する |
| 勝敗 | ダンジョンコア（魔力タンク）が破壊されなければ勝利。破壊されれば失敗で、再挑戦できる |
| 損失 | 壊れた施設と倒された配下は wave 終了後に復帰する。恒久的な損失はない |
| ダンジョンの成長 | Lv1から始まる。そのLvの最後の wave をクリアするとLvが上がる |
| 魔力 | 戦闘中に地下から湧き、タンクの上限まで貯まる。残量は持ち越す。供給量と上限は研究で改善する |
| 資材 | wave の間の採掘で得て、wave 終了時に獲得する |
| 資金 | wave クリアの報酬。クリア済みの wave の再挑戦では減額する |
| 配置 | 防衛施設・兵器・罠・防壁を準備中に自由配置する。戦闘中は建設・撤去をしない。撤去は全額返還 |
| 防衛経路 | 防壁の配置で作る。採掘で迷路を掘る方式は採用しない |
| 敵の侵入 | 盤面の外周から出現する。事前に分かるのは編成と方向の数だけで、固定の侵入口や予告マーカーを置かない |
| 完全封鎖 | 禁止しない。防壁は高い代償で通れるマスとして扱い、敵は迂回と破壊の安い方を選ぶ |
| メイン画面 | 採掘先の指定と、防衛施設・兵器・罠・防壁の配置を行う |
| 画面遷移 | メイン画面から研究画面、武器防具画面へ移動する |
| 画面領域 | 上下の帯で盤面を狭めない。下部に横幅いっぱいの帯を置かず、状況表示を設ける場合は上側のみとする |
| 不要な表示 | 「地下拠点」「配置を確認」「第1層／第一層」の常時ラベルと、＋／−のズームボタンは設けない |
| 盤面内の名称 | 施設・守備隊の名称は通常非表示。PCではマウスオーバー、スマホではタップした対象の名称だけを表示する |

以前のヘックス盤面は正方グリッドに置き換えた。魔力を実時間で蓄積する旧仕様（毎時6・上限70）は2026-11-17に廃止した。

## 資源の使い道

| 使い道 | 払う資源 |
| --- | --- |
| 設備の設置 | 資材と資金 |
| ユニット（配下）の雇用 | 資金 |
| 魔法研究 | 魔力と資金 |
| 武器研究 | 資金と資材 |

魔力はタンクが一つで、戦闘中の全体魔法と準備中の魔法研究の両方に使う。研究に払った分だけ、次の wave を少ない魔力で始めることになる。施設強化は1〜2種類の資源を消費する。強化に使う資源の内訳は未決。

## 役割

| 担当 | 役割 | 扱い |
| --- | --- | --- |
| コボルド | 岩盤の採掘。資材の獲得と盤面の拡張 | 採掘所の一部。個別に管理しない |
| ドワーフ | 武器防具の製作と改良（武器研究） | 工房の一部。個別に管理しない |
| エルフ射手 | 弓塔からの射撃 | 弓塔の一部。個別に管理しない |
| 魔術師 | 魔法塔からの攻撃 | 魔法塔の一部。個別に管理しない |
| 魔王 | 魔法研究、全体魔法 | 個別に扱う |
| 配下 | 迎撃、戦闘 | 個別に扱う。資金で雇用する |

施設の一部である人物の能力は、その施設の強化で伸ばす。配下にはデーモンやサキュバスなどの悪魔種族を想定している。各種族の能力と枠の数はまだ決めていない。種族固有の能力を原作由来として追加しない。

建設や修理の担当は設けない。壊れた施設は wave 終了後に自動で復旧する。

## 防衛の三つの手段

| 手段 | 判断する時点 | 役割 |
| --- | --- | --- |
| 施設（塔・罠・防壁） | 準備中 | どの方向から来ても時間を稼ぎ、一定の火力を出す |
| 配下 | 戦闘中 | 実際に敵が来た方向へ駆けつける |
| 全体魔法 | 戦闘中の一瞬 | 配下が間に合わない場所を即座に補う |

配下への指示は、戦闘中に配下をタップし、行き先をタップして移動させる。到着後は周囲の敵と自動で戦う。防壁は敵を止める設備ではなく、配下が到着するまでの時間を作る設備として位置づける。

## 画面ごとの扱い

メイン画面の兵器は設置する防衛設備を指す。武器防具画面は配下が使う武具の製作・改良（武器研究）を扱い、装備の割り当て方法は未決とする。研究画面では魔王の魔法研究を扱い、魔力の供給量と上限の改善を含む。これらを同じ「武器」として混在させない。

「研究室」「魔力核」「工房」「守備隊」などの盤面内ラベルを常時表示しない。名称は対象を確認する操作に応じて表示する。

準備中は配置の編集、戦闘中は配下への指示と全体魔法が操作の中心になる。通常の視点移動と設備の配置操作を明確に分け、仮置きを確認してから確定する方式は提案である。

盤面を広く見せるため、採掘・配置のボタンを左右下に背景帯なしで浮かせる配置は提案とする。ピンチ操作など、ボタンを使わない拡大縮小方法も候補であり、具体的な操作方式は未決である。

## 既存の試作との関係

`prototypes/landscape-ui.html` は2026-11-16時点の旧仕様で作った試作である。外観、配置操作、画面遷移、模擬襲撃の経路探索は参考になるが、魔力の実時間蓄積、準備中の採掘、10×8の盤面、初期配置、費用は現行仕様と異なる。詳細は[LEVEL_ONE.md](LEVEL_ONE.md)と[COMBAT.md](COMBAT.md)を参照。試作に登場する研究名、数値、鉱床の位置を確定仕様として扱わない。

## 今後決める事項

数値は試作で遊びながら決める。それ以外の主な未決事項は次のとおり。

- wave の終了条件（敵の全滅で終わるか、制限時間も設けるか）。
- 採掘所と工房を盤面に置くか。置く場合に敵の攻撃対象になるか。
- 盤面を広げ切った後の資材の入手方法。
- 配下の種族、枠の数、装備の割り当て方法。
- 全体魔法の種類と効果。魔王本人を盤面に出すか。
- 魔力以外の研究対象。
- ダンジョンLvごとの wave 数、最大Lv。
- エンジン、対象端末、保存方式、作品名。

ここにない数値や名称を、画面ラフや過去の提案から確定事項として補わない。決定・変更の履歴は[DECISIONS.md](DECISIONS.md)に記録する。
