# 防衛ゲーム 全体仕様

更新日：2026-11-16  
状態：初期設計。ユーザー確定事項と、提案・未確定事項を分けて記録する。

## 企画の中心

『魔王の始め方』に着想を得た、地下拠点を運営して侵入者を迎撃する防衛ゲーム。主人公は魔王を名乗る人間の魔術師で、琥珀色の魔力を特徴とする。プレイヤーは指揮官寄りの立場で、掘削、生産、研究、防衛を組み合わせる。原作について未確認の設定は追加せず、ゲーム独自の案を原作設定として扱わない。

Clash of Clansは画面の見た目と操作感の参考である。対人戦、オンライン運営、実時間の建設待ちなどを採用する決定は含まない。

## 確定している全体仕様

| 項目 | ユーザー確定事項 |
| --- | --- |
| 利用画面 | スマートフォンの横画面で遊びやすくする |
| 視点・盤面 | 2.5Dの斜め見下ろし。正方グリッドを斜めに描写する |
| ダンジョンの成長 | ダンジョンLv1から始まり、レベルアップしていく |
| 魔力の供給 | 地下から自動的に汲み上げる |
| 施設の強化 | 1〜2種類の資源を消費して施設をレベルアップする |
| 掘削 | 岩盤を掘って資源を獲得する |
| 防衛経路 | 掘削とは独立し、防壁の配置によって防衛経路を作る |
| 敵の侵入 | 侵入地点・方向は事前に分からない。固定の侵入口や、侵入地点を事前に示す予告マーカーを置かない |
| 配置 | 防衛施設・兵器・罠・防壁はプレイヤーが自由に配置する |
| メイン画面 | 掘削指示と、防衛施設・兵器・罠・防壁の配置を行う |
| 画面遷移 | メイン画面から研究画面、武器防具画面へ移動する |
| 画面領域 | 上下の帯で盤面を狭めない。下部に横幅いっぱいの帯を置かず、状況表示を設ける場合は上側のみとする |
| 不要な表示 | 「地下拠点」「配置を確認」「第1層／第一層」の常時ラベルと、＋／−のズームボタンは設けない |
| 盤面内の名称 | 施設・守備隊の名称は通常非表示。PCではマウスオーバー、スマホではタップした対象の名称だけを表示する |

以前のヘックス盤面は正方グリッドに置き換える。「掘削が敵の通路を作る」という旧案は採用しない。採掘対象の変化と敵の経路判定を分離し、採掘完了だけを理由に敵の進路が変わらない設計とする。

侵入地点・方向が事前に分からないことを前提に、複数方向への備えを考えられる配置設計とする。侵入地点の選択方法、出現可能な領域、敵を発見するタイミングは未確定。設置条件、通行を妨げる設置物、敵の経路選択も今後決める。

## 四つの役割

| 担当 | ユーザー確定の役割 | 未確定の境界 |
| --- | --- | --- |
| コボルド | 岩盤の掘削、資源獲得 | 運搬、建設、修理を担当するか |
| ドワーフ | 武器防具の製作と改良 | 防衛設備や罠の製造も担当するか |
| 魔王 | 研究、全体魔法 | 研究対象、魔法の効果・費用・使用条件 |
| 配下 | 迎撃、戦闘 | 兵種、召喚方法、編成、行動指示の詳細 |

配下にはデーモンやサキュバスなどの悪魔種族を想定している。各種族の能力、加入・召喚条件、消費資源はまだ決めていない。種族固有の能力を原作由来として追加しない。

採掘、生産、研究、迎撃という役割分担を基本にする。資源を各工程へどう配分するか、研究が製作や戦闘をどう変えるかは、次の設計で具体化する。研究を「新しい技術の解禁」、ドワーフの改良を「既存装備の性能向上」と分ける考え方は提案段階である。

弓塔にはエルフの射手、魔法塔には魔術師がいる表現を新たな方針とする。塔へ誰をどう配属するか、駐留者を個別の配下として管理するかは未確定である。

## 成長とLv1の経済試作

資源は魔力・資材・資金の3種類を採用案として試す。魔力は地下からの自動供給、資材はコボルドの採掘で得る。資金の継続的な入手元は未決で、迎撃報酬は候補に留める。

今回のブラウザ試作はダンジョンLv1の準備操作と経済が対象である。自動魔力、採掘、配置費用、施設Lv1からLv2への強化を扱い、ダンジョン自体のLv2進行は含めない。数値はすべて仮で、[LEVEL_ONE.md](LEVEL_ONE.md)にまとめる。資金収入、戦闘、3Dアセット導入は未実装である。

待つことで補充される魔力、作業を指示して得る資材、試作では初期分だけの資金という違いを設ける。魔力供給の強化、金銭を使う弓塔の増設、魔力を使う魔法塔の増設など、限られた資源の使い先を判断できるかを検証する。

## 画面ごとの扱い

メイン画面の兵器は設置する防衛設備を指す。武器防具画面は配下が使う武具の製作・改良を扱い、装備の割り当て方法は未確定とする。研究画面では魔王の研究を扱う。これらを同じ「武器」として混在させない。

Lv1試作では研究・工房を各画面で扱い、盤面の初期建物からは省く。世界に研究室や工房が存在しないと決めたものではない。人物と塔の駐留者は図形による仮表示とする。

「研究室」「魔力核」「工房」「守備隊」などの盤面内ラベルを常時表示しない。名称は対象を確認する操作に応じて表示する。この表示ルールは、仮置きの魔力核や施設名をゲームの確定設定にするものではない。

横画面の操作案として、通常の視点移動と設備の配置操作を明確に分け、仮置きを確認してから確定する方式がある。準備中は配置編集、戦闘中は指揮と全体魔法を中心にする案もあるが、編集可能なタイミングはまだ固定しない。

盤面を広く見せるため、掘削・配置のボタンを左右下に背景帯なしで浮かせる配置は実装上の提案とする。ピンチ操作など、ボタンを使わない拡大縮小方法も候補であり、具体的な操作方式は未確定である。

画面ラフは構図と画面遷移の検討資料であり、敵の出現・侵入地点の選択・戦闘ロジックは未実装である。侵入に関する確定事項は今後のゲーム本体の設計条件となる。ラフに登場する研究名、数値、魔力核、鉱床の位置などは確定仕様ではない。採掘地点を画面周辺の専用帯に置く構成も、必須の配置条件にしない。

## 今後決める事項

勝敗条件と敵が目指す対象、魔王本人の移動・直接操作、全体魔法の使用制約、研究と生産の費用・時間、資金の入手元、建設担当、塔の配属方法を決める必要がある。魔力核を守る方式や主人公の死亡を敗北とする方式は未採用である。

初期盤面の大きさ、フロア数、ダンジョンLv2の解放条件、最大レベル、保存方式も未確定。ここにない数値や名称を、画面ラフや過去の提案から確定事項として補わない。決定・変更の履歴は[DECISIONS.md](DECISIONS.md)に記録する。
