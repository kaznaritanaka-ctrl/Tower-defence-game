# 全体設計

更新日：2026-11-17  
状態：ゲーム全体の骨格をまとめた資料。2026-11-16〜17の協議でユーザーが承認した事項を「確定」、承認を得ていない案を「提案」、まだ決めていない事項を「未決」として区別する。数値は試作で遊びながら決める方針で、初期盤面の大きさ以外はこの資料で扱わない。

この資料は、個別仕様（[GAME_DESIGN.md](GAME_DESIGN.md)、[LEVEL_ONE.md](LEVEL_ONE.md)、[COMBAT.md](COMBAT.md)）をつなぐ上位の設計を定める。既存資料と食い違う箇所は末尾の「既存資料の状態」にまとめた。食い違う場合はこの資料の確定事項を優先する。

## 1. ゲームの形

**確定**

- 一人で遊ぶゲーム。対人戦やオンライン運営は想定しない。
- 進行の単位は wave。wave をクリアすると次の wave が解禁される。
- 襲撃はプレイヤーが自分で開始する。準備が整うまで敵は来ない。
- 戦闘はプレイヤーが見ながら指揮する。
- 実時間の待ち時間で進行を止めない。ゲームの時計は実時間ではなく wave とする。
- 開発エンジンは Godot 4.7系とする。
- 対象端末は Android とする。iPhone向けは、書き出しに必要なMacがないため対象にしない。

**1サイクルの流れ**

```
準備（施設の配置・強化、研究、装備、採掘先の指定）
  ↓ プレイヤーが襲撃を開始
戦闘（施設が自動迎撃、配下へ移動指示、全体魔法）
  ↓
結果（クリア：資金を獲得し次の wave を解禁 ／ 失敗：再挑戦）
  ↓ どちらの場合も採掘分の資材を獲得
準備へ戻る
```

## 2. 勝敗

**確定**

- 守る対象はダンジョンコア（魔力タンク）。現在の試作で魔力井（仮称）と呼んでいる設備に当たる。
- wave は敵が全滅した時点で終わる。制限時間は設けない。
- wave が終わるまでダンジョンコアが破壊されなければ勝利。被害の大きさによる成績評価は設けない。
- ダンジョンコアが破壊されると失敗。報酬はなく、同じ wave に再挑戦できる。
- 壊れた施設は戦闘後に自動で復旧する。倒された配下も wave 終了後に復帰する。恒久的な損失はない。

## 3. 資源

**確定**

| 資源 | 入手方法 | 性格 |
| --- | --- | --- |
| 魔力 | 戦闘中に地下から秒単位で湧き、タンクの上限まで貯まる。残量は持ち越す | 全体魔法の燃料と、魔法研究の費用 |
| 資材 | 採掘。wave の間に掘り、wave 終了時に獲得する。失敗した wave でも掘った分は入る | wave を重ねた見返り |
| 資金 | wave クリアの報酬 | 難しい wave を越えた見返り |

- 魔力の供給量と上限は研究で改善する。供給量は魔法を撃てる回数に、上限は撃てる魔法の大きさに効く。
- 資源の使い道は次のとおり。

| 使い道 | 払う資源 |
| --- | --- |
| 設備の設置 | 資材と資金 |
| ユニット（配下）の雇用 | 資金 |
| 魔法研究 | 魔力と資金 |
| 武器研究 | 資金と資材 |

- クリア済みの wave に再挑戦できる。初回クリアは満額、2回目以降の報酬は減額する。
- 設置した施設の撤去は全額返還する。詰まったときは、まず配置を組み直せるようにする。
- 準備中に採掘の完了を待つ時間は設けない。準備中に決めるのは採掘先だけとする。
- 旧仕様の「毎時6・上限70の実時間蓄積」「非表示・オフライン中の蓄積」は廃止する。
- 魔力はダンジョンコア（魔力タンク）に貯まり、戦闘終了時の残量を次へ持ち越す。準備中はその残量から魔法研究の費用を払い、次の wave は残った量から始まる。戦闘で魔法を撃つか、研究のために残すかが選択になる。

## 4. 防衛の三つの手段

**確定**

| 手段 | 判断する時点 | 役割 | 弱点 |
| --- | --- | --- | --- |
| 施設（塔・罠・防壁） | 準備中 | どの方向から来ても時間を稼ぎ、一定の火力を出す | 動かせない。全方向に置くと薄くなる |
| 配下（悪魔種族） | 戦闘中 | 実際に敵が来た方向へ駆けつける | 数が少ない。移動に時間がかかる |
| 全体魔法（魔王） | 戦闘中の一瞬 | 配下が間に合わない場所を即座に補う | 魔力の量と湧く速さに縛られる |

- 防壁は敵を止める設備ではなく、配下が到着するまでの時間を作る設備として位置づける。
- 配下への指示は、戦闘中に配下をタップし、行き先をタップして移動させる。到着後は周囲の敵と自動で戦う。
- 戦闘中は施設の建設・撤去をしない。施設は事前の読み、配下と魔法は戦闘中の対応とする。

- 最初の全体魔法は、数秒間の全体攻撃力アップとする。
- 最初の配下は次の2種とする。

| 配下 | 役割 | 見た目 |
| --- | --- | --- |
| デーモン | 純粋に戦闘力が高い | 4本腕。バフォメットを思わせる姿 |
| サキュバス | 幻惑魔法を使う | 女性のキャラクター |

**提案**

- 配下の数は、スマホ横画面で扱える範囲としてダンジョンLv1では2〜4体に絞る。

## 5. 登場する人物の扱い

**確定**

| 扱い | 対象 |
| --- | --- |
| 施設の一部として扱い、個別に管理しない | コボルド（採掘所）、ドワーフ（工房）、エルフ射手（弓塔）、魔術師（魔法塔） |
| 個別に扱う | 配下（悪魔種族）、魔王 |

- 施設の一部である人物の能力は、その施設の強化で伸ばす。
- ドワーフが製作・改良する武器防具は、配下の装備を対象とする。
- 魔王は研究と全体魔法、配下は迎撃・戦闘という役割は従来どおり。

## 6. 盤面と採掘

**確定**

- 初期の盤面は7×7程度とする。
- 盤面の周辺にある岩盤を採掘すると、盤面が広がる。
- 採掘は資材の入手と盤面の拡張を兼ねる。
- 防衛経路は防壁の配置で作る。採掘で迷路を掘る方式（旧ヘックス案）には戻さない。
- 採掘所は当面、拡張を担当するコボルドが出入りする動きを見せるためだけの設備とする。簡易化のため、ゲーム上の機能は持たせない。

**提案**

- 盤面の拡張は wave 終了時に反映する。戦闘中に盤面の形は変わらない。
- 敵は、拡張後の盤面の外周から出現する。盤面を広げるほど、守る外周は長くなり、ダンジョンコアまでの距離は伸びる。
- ダンジョンLvは、採掘で広げられる範囲の上限を決める。

従来の確定事項「掘削によって敵の進路は変わらない」は、次のように読み替える。採掘の指定や進行は戦闘中の経路に影響しない。ただし wave 終了時に盤面が広がった結果として、次の wave の出現位置と経路は変わる。

## 7. ダンジョンLv

**確定**

- ダンジョンLvは wave のまとまりで、章の役割を持つ。
- そのLvの最後の wave をクリアすると、ダンジョンLvが上がる。
- Lvが上がると、採掘で広げられる範囲、施設の種類と設置上限、施設レベルの上限、配下の枠、敵の種類が増える。
- 施設・研究・装備・資源はすべて次のLvへ持ち越す。
- 施設レベルの上限はダンジョンLvで決まる。二つのレベルは別に管理する。

## 8. 侵入ルール

**確定**

| 項目 | 内容 |
| --- | --- |
| 出現する範囲 | 盤面の外周全体 |
| 事前に分かること | 敵の編成と、何方向から来るか（方向の数） |
| 事前に分からないこと | どの辺のどこから来るか。wave 開始時に抽選し、予告マーカーは出さない |
| 発見のタイミング | 外周に現れた瞬間に見える。複数の集団は時間差で別方向から現れる |
| 敵の狙い | 基本はダンジョンコアへ向かう |
| 完全封鎖 | 禁止しない。防壁は通行に高い代償がかかるマスとして扱い、迂回より壊す方が安ければ壊して進む |

- 採掘と経路の関係は6章のとおり。
- 完全封鎖の扱いは、模擬襲撃の実装（防壁を高コストの通行障害とする経路探索）と同じ考え方とする。

**後のLvで足す候補**

- 兵種ごとに狙いを変える（塔を優先する弓兵など）。
- 敵の出現を早く察知できる研究。

## 9. 従来の確定事項で維持するもの

- スマートフォンの横画面。正方グリッドを斜めから見る2.5D。
- 防衛施設・罠・防壁の自由配置。
- メイン画面で掘削指示と配置を行い、研究画面・武器防具画面へ移動する。
- 上下の帯で盤面を狭めない。施設名は通常非表示とし、マウスオーバーまたはタップで表示する。
- 暗い青灰色の洞窟・石材と琥珀色の魔力。
- 主人公は魔王を名乗る人間の魔術師。プレイヤーは指揮官寄りの立場。

## 11. 次に作る範囲（提案）

Godot 4.7系で wave 構造の最小の試作を作り、骨格が面白いかを確かめる。既存のHTML試作は組み替えず、外観と操作の参考として残す。Godotのプロジェクトは未作成である。

**検証する問い：** 方向の分からない侵入に対して、施設で薄く備え、配下と全体魔法で厚くする判断が面白いか。

**範囲**

1. 7×7の盤面で、ダンジョンLv1の wave を3つ用意し、クリアで次を解禁する。
2. 魔力を戦闘中に湧く資源へ変更し、全体魔法（数秒間の全体攻撃力アップ）を入れる。
3. 配下としてデーモンとサキュバスを置き、タップで移動を指示できるようにする。
4. wave クリアで資金、wave 終了で資材を獲得し、採掘した周辺の岩盤の分だけ盤面を広げる。再挑戦は減額、撤去は全額返還とする。
5. wave 開始前に、敵の編成と方向の数を表示する。

**完了条件：** 3つの wave を通して遊べる。配置を変えると結果が変わる。同じ wave の再挑戦で侵入方向が変わり、展開が変わる。準備中に待ち時間が発生しない。

この試作の結果を見てから、本体の実装範囲を決める。
