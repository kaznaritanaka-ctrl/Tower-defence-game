## 採用時の扱い

KayKit は同シリーズの環境・人型・動作を組み合わせる検証候補とする。まず少数を読み込み、横画面の斜め見下ろしで、壁・罠・配下が見分けられるかを確認する。最終的な絵柄や描画方式の採用決定ではない。

コボルド、ドワーフ、デーモン、サキュバスについて、今回の候補に希望する外観がそろっているとは確認していない。種族ごとのモデル、魔王の衣装、琥珀色の魔法表現は別途選定・制作する。

`prototypes/landscape-ui.html` は画面構成を検討するための 2D 描画によるラフである。上表の 3D モデル、アニメーション、AI アドオンを組み込んだゲームではない。

採用した配布物について、取得元 URL、版、利用するファイル、同梱ライセンスを記録する。ここで確認したページ上の表示を、未確認の追加素材や別商品へ一律に適用しない。現段階では、上表の3D素材・アニメーション・AIアドオンは同梱していない。
